# Prince Sarfo Acheampong — Portfolio

A responsive single-page portfolio for Prince Sarfo Acheampong, focused on Remote Sensing, GIS, Agricultural Engineering and environmental research.

## Files
- `index.html` — portfolio structure/content
- `styles.css` — responsive design and earth-tone visual system
- `script.js` — mobile navigation, current year, mailto contact form
- `assets/` — uploaded project visuals and a clearly labeled Lake Bosomtwe placeholder visual

## Before publishing
1. Replace `assets/lake-bosomtwe-placeholder.svg` with the final Lake Bosomtwe NDTI map when available.
2. Add the user's GitHub profile URL in `index.html` where marked "GitHub profile — add URL".
3. If desired, connect the contact form to Formspree, Netlify Forms, or a custom backend instead of `mailto:`.
4. Publish the folder to GitHub Pages, Netlify, Vercel, or another static hosting provider.
